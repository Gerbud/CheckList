# Правила проекта

## GitHub

- После завершения любых изменений кода, конфигурации, миграций или документации проверять результат, создавать Git-коммит и отправлять его в GitHub в текущую рабочую ветку.
- Не оставлять готовые изменения только в локальном рабочем дереве, если пользователь явно не попросил не выполнять commit или push.
- Перед коммитом не добавлять секреты, локальные базы данных, пользовательские загрузки, временные и сгенерированные рабочие файлы. При необходимости добавлять такие пути в `.gitignore`.
- В итоговом сообщении указывать ветку и идентификатор отправленного коммита.
