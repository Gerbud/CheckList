# Модуль обмена гарантийными обращениями

Каталог `pinel.warrantysync` — готовый локальный модуль для коробочного «1С-Битрикс: Управление сайтом».

Скопируйте его как `/local/modules/pinel.warrantysync`. После установки Bitrix создаст публичную точку `/warranty-sync/`. Удаление модуля удаляет только эту точку и настройки модуля; таблицы `warranty` и `warranty_log` не удаляются.

API принимает только подписанные JSON POST-запросы. Доступные операции: проверка здоровья, инкрементальное чтение обращений и обновление разрешённых полей `UF_STATUS`, `UF_COMMENT`.

Код совместим с PHP 5.6, который обнаружен на текущем Beget-сервере.
